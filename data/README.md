# Frozen data

processed/annual_reverified.csv contains the complete236×35 annual grid and model covariates. processed/original_source_rows.csv retains the original RP/QV measurements,flags,keys and source hashes from which principal outcomes are rebuilt. processed/panel_country_year.csv is the Phase1 preprocessing snapshot. source_extracts/ contains only selected RP/QV/RL/QI source records;entire bulk databases are not redistributed. metadata/ retains crosswalks,quality flags,source notes,definitions and the source register.
