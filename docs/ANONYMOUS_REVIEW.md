# Anonymous review access

The working repository remains PRIVATE. GitHub account ownership and server-side events can identify a depositor even when files and local Git author fields are neutral;private GitHub is not itself a reviewer access service. Do not put an identifying repository URL into the anonymous manuscript or invite reviewers directly from this personal account.

The preferred current route is an independent **anonymous reproducibility ZIP** submitted through the journal system as a supplementary review file. It contains this repository's data,code,results and documentation,but no .git directory,remote configuration,account-specific URL,local absolute paths,credentials or manuscript files. Its citation metadata deliberately withholds author identities. The GitHub archive and anonymous ZIP correspond to the same frozen scientific content.

The archive is prepared for upload;no journal submission or reviewer invitation has been sent. Once attached to the submission,reviewers can access it through the editorial system without GitHub login. This route needs no disclosure of the repository owner. If a hosted anonymous URL is later preferred,use a repository service's blinded view-only link and test it logged-out before placing it in the manuscript;such a link has not been created here.

[EDS instructions](https://link.springer.com/journal/10668/submission-guidelines) describe double-blind review and encourage anonymisation of reviewer-facing research data. The supplied attachment is the concrete anonymous route prepared in this task;actual editorial-system access remains dependent on attaching it during submission. Public release requires separate authorisation and coordination with the journal's review arrangement.
